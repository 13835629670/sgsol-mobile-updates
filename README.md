## 如何更新

使用免令牌版 APK：暂停助手循环 → 旧版手气卡或邮件助手的「助手更新」→「检查并下载更新」→ 等待已验签保存 → 彻底关闭游戏进程后重开。新版更新入口位于「更多 → 助手更新」。

无需 GitHub 账号或令牌；不需要配置发布者的本机代理端口。

公开签名包：[latest.json](https://raw.githubusercontent.com/13835629670/sgsol-mobile-updates/main/latest.json)。此 JSON 是供助手下载的签名代码包，不是 APK，不要自行取消验签执行。

## 旧版首次迁移

旧 0.4.0～0.6.2/layout2 APK 的加载器内置令牌必填检查。仅将仓库公开不会改变旧 APK：先向发布者获取并覆盖安装一次 `sgsol-mobile-0.6.2-public1-signed.apk`，不要卸载或清数据。之后可免令牌更新脚本。这个 APK 已内置 sequence 9，当前没有更高序号时提示「没有更新版本」属于正常。

脚本下载后不会即时替换正在运行的助手，也不会自动登录或领取。验签失败不会应用；新脚本未完成启动确认时，下次启动回退。菜单可选择「下次使用内置版」。加载器或安卓原生部分更新仍需 APK。

本仓库仅发布签名助手代码和说明，不包含签名私钥、账号配置、令牌、运行日志或官方游戏 APK。历史版本可从 Git 历史查看，但客户端拒绝旧序号和已回退序号。
